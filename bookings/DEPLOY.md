# julix.mxdesign.uk/bookings

Private booking-confirmation tool for Julix (PDF confirmation, WhatsApp message, calendar block).
Not linked from the site and marked noindex.

Deploy: upload `index.html` into a `bookings` folder inside the julix.mxdesign.uk web root
on Hostinger (usually `public_html/julix/bookings/`). The page is then at
https://julix.mxdesign.uk/bookings/

The root robots.txt is not changed; the page carries its own noindex tag.
